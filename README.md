# Number-Guess 🎮

A simple, interactive terminal-based number guessing game written in C++. 

## How to Play
1. The program selects a random number within a specific range.
2. The player attempts to guess the number.
3. The program provides feedback (e.g., "Too high" or "Too low") after each guess until the player finds the correct number.

## Requirements
To run this game locally, you need a C++ compiler installed on your system (such as `g++` or `clang`).

## How to Run (Linux/macOS Terminal)

1. Clone or download this repository.
2. Open your terminal and navigate to the directory.
3. Compile the code:
   ```bash
   g++ guess.cpp -o guess
   ```
4. Run the executable:
   ```bash
   ./guess
   ```
